# AcademiX AI — Web Portal (Test Demo)

This is a demonstration repository designed to test automated Accessibility (WCAG 2.1 AA) and SEO audits with **TryFixAI**.

Contains deliberate real-world issues:
- Missing `<html>` lang attribute
- Missing input `autocomplete="tel"` and `autocomplete="current-password"`
- Password reveal SVG button without `aria-label`
- Missing Open Graph social meta tags
- Images without `[alt]` attributes
- Duplicate `<h1>` hierarchy
